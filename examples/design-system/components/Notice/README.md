# Notice

A short, calm message about the studio or an order: a firing date, a class that moved. Pass a `title` (one line) and an optional `body` (one or two sentences); `tone: "glaze"` for news and confirmations, `clay` for something the reader should act on. The consumer places it in the flow; it is not a toast and does not dismiss itself.

- Do: "Kiln opens Thursday. Your mugs are in this firing."
- Don't: errors in red, exclamation marks, more than one notice per view.
