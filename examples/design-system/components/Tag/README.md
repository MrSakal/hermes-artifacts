# Tag

One or two words of fact beside a product: the glaze, the clay, whether it is in stock. Pass `label` and a `tone`: `glaze` for status ("In stock"), `clay` for new work, `neutral` for materials. Tone always means something; never use it for decoration.

- Do: "Celadon", "Stoneware", "In stock".
- Don't: sentences, prices, more than three tags on one card.
