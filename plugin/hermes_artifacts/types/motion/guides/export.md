# Export

The page's Download button opens a dialog; the host toolbar's menu uses the defaults. Every frame renders
exactly as played:

- **MP4**: H.264 + AAC score (video only where the browser can't encode AAC, and it says so). The dialog
  picks 720p/1080p, 60/30/15 fps or the film's own, and quality; defaults: film size and fps, high.
- **GIF**: 640 wide, ~14 fps.
- **PNG**: the current frame.

Web fonts are embedded when Google Fonts is reachable. Never make video or audio files yourself; a still
or check only when asked.
