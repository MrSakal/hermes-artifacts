name: make
description: Make a doc, spreadsheet, deck, whiteboard or dashboard
---

What the user asks you to make to look at, use, keep or share (a doc, report, spreadsheet, budget, deck, whiteboard, flowchart, dashboard, design, page) is an artifact, not a file: call ha_guide with its type, then ha_publish.
Not in your tool list? Find them with tool_search "artifacts" and load them with tool_describe.
Only when the user names a file format (.xlsx, .docx, .pptx, .pdf) or the file belongs in a codebase, write the file instead.
